# Inti i18n

Tujuan: UI bisa ganti bahasa; tahap ini Indonesia dan Inggris.
Selesai: crate `wangungis-i18n` (`Lang` 16 bahasa, `t`, `tf`, fallback bahasa aktif lalu en, id, kunci). Katalog `id.json` dan `en.json`, 292 kunci. Teks di `ui`, `tools`, `pointcloud` jadi kunci. Menu Berkas > "Bahasa / Language", pilihan disimpan di `~/.wangungis/lang`, bawaan `id`.
Pembagian kerja: kode dan terjemahan en oleh Sonnet effort medium; review, gate, uji jendela, perbaikan "1 tiles", commit oleh Opus.
Keputusan: `EditError::Unsupported` membawa kunci. Nama cat dan nama node bawaan disimpan dalam bahasa saat dibuat, sebagai data. Ganti bahasa mereset buka-tutup panel egui.
Keputusan: test yang membandingkan teks kini membandingkan kunci yang setara (`tools/tests/tools.rs`, `camera.rs`, `icons.rs`). Test scan memastikan setiap kunci di sumber ada di katalog dan sebaliknya.
Terlihat di jendela asli: bahasa Inggris tampil di menu, panel, status bar, dan baris petunjuk.
Belum: 14 bahasa lain masih fallback ke Inggris, font non-Latin belum ada (PR C, PR D).

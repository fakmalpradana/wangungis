# Font Noto

Tujuan: semua 16 bahasa UI tampil tanpa kotak kosong.
Selesai: lima font Noto Regular di `ui/fonts/` dengan lisensi OFL per keluarga. `ui/src/fonts.rs` menambahkannya sebagai fallback setelah font egui. Satu wajah CJK per bahasa (JP 0, KR 1, SC 2, TC 3). ADR-010.
Pembagian kerja: unduh, verifikasi indeks wajah TTC dan SHA-256, ukur, dan uji jendela oleh Opus; kode, test, dan draf ADR oleh Sonnet effort medium.
Hasil ukur: biner 19,2 MB menjadi 39,6 MB, RSS tetap 108-112 MB. Angka RSS pertama (79 MB) ternyata pencilan, jadi diukur ulang tiga kali bergantian.
Test: setiap karakter di semua katalog dan nama bahasa punya glyph, untuk ke-16 bahasa.
Terlihat di jendela asli: menu bahasa menampilkan CJK, Hangul, Arab tersambung, Thai, dan Devanagari.
Belum: terjemahan 14 bahasa (PR D). Arab tetap kiri-ke-kanan.
